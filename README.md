# Лили Вяжет — маркетплейс изделий ручной работы

Площадка, где частные мастерицы открывают свои страницы с фото и видео,
а покупатели заказывают изделия и платят картой. Площадка берёт 10% с суммы
работ в оплаченном заказе (доставка мастерице достаётся полностью).

## Из чего состоит

| Папка | Что внутри |
| --- | --- |
| `pages/` | Страницы сайта |
| `components/` | Общие части интерфейса |
| `lib/` | Работа с Supabase, форматирование, темы, загрузка файлов |
| `styles/` | Оформление (Tailwind + фирменное «северное сияние») |
| `supabase/migrations/` | SQL для базы данных — выполняется в панели Supabase |
| `supabase/functions/` | Приём оплаты через ЮKassa |
| `.github/workflows/` | Автоматическая сборка и публикация на GitHub Pages |

## Порядок первого запуска

Полная пошаговая инструкция — в файле **`ИНСТРУКЦИЯ.md`**. Коротко:

1. Выполнить `supabase/migrations/001_marketplace.sql` в Supabase → SQL Editor.
2. Прописать три секрета в настройках репозитория на GitHub.
3. Опубликовать две функции оплаты и подключить ЮKassa.

## Роли

- **Покупатель** — заказывает и оплачивает, подаёт заявку на мастерскую.
- **Мастерица** — своя страница, работы, видео, заказы, трек-номера.
- **Администратор** — заявки, заказы, выплаты, пользователи, комиссия.

## Важное о безопасности

Цены, стоимость доставки и комиссия считаются **на сервере** в функции
`place_order`. Браузер передаёт только список товаров и адрес — подменить
сумму из консоли невозможно. Роль пользователя защищена триггером: сменить
её может лишь администратор.
